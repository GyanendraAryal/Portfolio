# 🚀 Premium Full-Stack Portfolio Ecosystem

A production-grade, industry-standard MERN stack portfolio featuring a high-end design system, minimalist glassmorphism, and a secure administrative command center. Engineered for performance, scalability, and visual excellence.

## ✨ Core Philosophy

This project transcends a simple portfolio; it is a meticulously crafted digital experience. It focuses on:
- **Visual Storytelling**: Using motion and transparency to guide the user.
- **Atomic Architecture**: Decoupled frontend/backend with clean, maintainable patterns.
- **Administrative Control**: A complete, private ecosystem for real-time artifact management.

---

## 🛠️ Technical Architecture

### Frontend (The Visual Engine)
- **Framework**: React 19 + Vite (Next-gen bundling)
- **Styling**: Tailwind CSS + Vanilla CSS Transitions
- **Animations**: Framer Motion (Orchestrated staggered transitions)
- **State**: Zustand (Atomic, lightning-fast state management)
- **Icons**: Lucide React (Pixel-perfect SVG vectors)
- **Optimization**: Route-based code splitting & Vendor chunking

### Backend (The Intelligence Layer)
- **Engine**: Node.js + Express 5
- **Database**: MongoDB + Mongoose (Schema-driven integrity)
- **Validation**: Zod (Type-safe request scrubbing)
- **Security**: JWT Authentication + Helmet + Rate Limiting
- **Assets**: Cloudinary API (Professional media delivery)

## 🚀 Deployment & Configuration

### Environment Setup
Create a `.env` in the `server` directory:
```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secure_secret
PORT=5000
NODE_ENV=production
CLOUDINARY_CLOUD_NAME=...
CLOUDINARY_API_KEY=...
CLOUDINARY_API_SECRET=...
FRONTEND_URL=your_production_domain
```

Create a `.env` in the `client` directory:
```env
VITE_API_URL=https://your-api-domain.com/api
```

### Installation
```bash
# Install server dependencies
cd server && npm install

# Install client dependencies
cd client && npm install

# Launch Development Spectrum
# (Run in separate terminals)
npm run dev
```
